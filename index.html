2. Intro

Le système permet d'automatiser un arrosage en récupérant le pourcentage d'humidité du sol. Le systeme d'arrosage peut être desactivé pour ne laisser que l'affichage du pourcentage

3. Composants

Raspberry Pi Pico

Le cerveau du système qui traite les données

Capteur d'humidité

Mesure l'humidité du sol

Écran OLED

Interface visuelle pour lire les données

Interrupteur

Contrôle manuel pour activer le système d'arrosage

LED (Simulateur Pompe)

Représente visuellement l'activation de la pompe

4. Le Problème

Quand les deux broches du capteur d'humidité était touchées en meme temps le code plantait

La Solution

Nous savons tout simplement changé de capteur d'humidité pour un avec la connectique grove (pico = grove, ancien hum ≠ grove)
